# 🌤️ Python Weather App

A simple, interactive command-line Weather App built with Python. It fetches real-time weather data for any city in the world without requiring an API key.

## 🚀 Features
- Get real-time weather for any city
- Displays temperature, condition, humidity, and wind speed
- No API key required (uses free wttr.in service)
- Interactive command-line interface
- Error handling for invalid city names

## 🛠️ Tech Stack
- Python 3.x
- Requests library
- wttr.in (Free Weather API)
